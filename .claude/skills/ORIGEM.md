# De onde vieram estas skills

Doze skills copiadas de
[gamedev-skills/awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills)
(commit `c6ca6c4`, licença Apache-2.0 — ver `LICENSE-gamedev-skills` e `NOTICE-gamedev-skills`),
em 13/11/2026, a pedido do dono. São guias em texto (SKILL.md + referências), sem scripts.

Ficaram só as que servem a este jogo (three.js no navegador):

- `threejs-scene-setup`, `threejs-materials-lighting`, `threejs-gltf-loading`
- `performance-optimization`, `game-feel`, `game-ui-ux`, `camera-systems`, `game-ai`,
  `save-systems`, `audio-design`, `input-systems`, `shader-programming`

Atenção: as de three.js foram escritas para a **r187**; o jogo usa a **r160**
(`three@0.160.0`). O que elas dizem de API vale conferir contra a r160 antes de usar.

O roteador da coleção e as skills de outros motores (Godot, Unity, Unreal, Roblox…)
não foram copiados.
